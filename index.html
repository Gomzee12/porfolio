A bit about me
Not the usual "I'm passionate about technology" intro. Here's who I actually am.

I'm Gomzee — a first-year computer science student at NST-RU who got into programming because I wanted to automate my homework. That didn't work out, but I ended up falling in love with building software anyway.

Right now I'm deep into Python and Java. Python for its speed of prototyping, Java for when I want to feel like a proper engineer. I spend most evenings either writing code or playing badminton — sometimes thinking about code while playing badminton.

I'm not the "10x developer" type (yet). I'm the "stayed up till 3am debugging a semicolon" type. And honestly, that's how you learn.
